# 蘇SIR：今日訓導檢查手機櫃

用電筒照儲物櫃門嘅一條罅隙，記住冇交機嘅格——一隻喺瀏覽器即玩、以手機或 iPad 打直為主嘅資訊科技週小品。題材係觀察同記憶，語氣輕鬆，亦唔會羞辱學生。

玩法好短：**60 秒檢查時間，記住冇交機嘅格。之後 20 秒，揀返出嚟。**

線上試玩：<https://tlc-cmyk.github.io/hai-gwong/>

## 點玩

1. 打開 `index.html`（或上面嘅 GitHub Pages 連結）。請將 iPad 或手機打直，揀班別（1A 至 6D）同學號（1 至 40），再撳「開始檢查手機櫃」。
2. **60 秒檢查時間，記住冇交機嘅格。** 中一至中六可滑動換頁。電話打橫放。
3. **之後 20 秒，揀返出嚟。** 再撳一次可取消。
4. 排行榜第 1 至 20 名。每個年級 160 格（編號例如 1A01–1D40、6A01–6D40），合共 60 格空櫃，隨機分落中一至中六；計時六頁共用。結果會顯示評級、分數同自我最佳。

標題、遊戲同結果畫面都有「聲音：開／關」。若裝置打橫，開始畫面會用全畫面提示要打直。桌面瀏覽器用滑鼠移動即可照櫃；亦可用底部年級掣或滾輪換頁。

## 操作一覽

| 操作 | 作用 |
| --- | --- |
| 移動滑鼠（檢查階段） | 電筒光圈跟隨，無須點擊即可從罅隙查看 |
| 手指按住並移動（檢查階段） | 手指即電筒；光圈略為上移 |
| 左右滑動／撳年級／滾輪／方向鍵 | 喺中一至中六換頁（檢查同點選階段都得） |
| 點擊／輕觸櫃格（點選階段） | 選取或取消「冇交機」標記 |
| 「聲音：開／關」 | 靜音或開聲 |

檢查階段掃柜時，普通左右移動電筒唔會換頁；快速橫向輕掃、從上下邊緣或兩側開始滑，或者用底部年級掣，先會翻去下一版。

## 評級

分數：每查中一格 +100，每誤報一格 −25，最低 0 分。六十格全中且零誤報為 6000 分。

| 條件 | 評級 |
| --- | --- |
| 60 格全中，零誤報 | 火眼金睛 |
| 至少 45 格查中，誤報不多於 2 | 細心值日 |
| 至少 38 格查中且誤報不多於 4，或至少 30 格查中且誤報不多於 2 | 合格 |
| 至少 23 格查中，誤報不多於 6 | 漏咗幾格 |
| 誤報至少 30 格，而且誤報多過查中 | 亂點 |
| 其餘（包括完全唔點） | 要再練 |

最佳分數存在瀏覽器 localStorage（鍵名 `hai-gwong-best-v5`，同舊版 24 格／四個年級／120 格櫃牆嘅紀錄分開）。

## 技術

- 單資料夾靜態網頁：`index.html`、`style.css`、`engine.js`、`audio.js`、`game.js`，無建置步驟、無外部 CDN。
- 畫面用 Canvas 即場繪製（原創扁平描邊校園風：乳白色走廊、雜色儲物櫃、電筒圓光）。每個年級嘅櫃牆為 10×16＝160 格，配合直立畫面；櫃門寫住 1A01 呢類編號。從櫃隙睇進去，電話係打橫而且較薄嘅機身。
- 聲音用 Web Audio 即時合成（柔和電筒低鳴、照櫃輕響、點選、校鐘、倒數提示、結果短句），唔靠取樣檔。
- 玩法邏輯集中喺 `engine.js`，可以用 Node 做無介面測試：

```bash
node test-engine.mjs
```

測試會檢查：標題「蘇SIR：今日訓導檢查手機櫃」、六個年級各 160 格櫃（編號 1A01–6D40）、合共 60 格空櫃隨機分落各年級（每頁至少 1 格）、每頁顏色互異、60 秒檢查後 20 秒點選（換頁唔會重設計時或重抽空櫃）、只有檢查階段而且光圈蓋住當前頁櫃隙先可以看見內容、點選階段不能偷睇、評分同評級、名稱須為班別 1A 至 6D 加學號 1 至 40（例如 1A01、6D40）、排行榜按分數同較早時間排序並只取頭 20 名，以及「先照晒六頁所有空櫃再準確點選」嘅記憶機械人會得到「火眼金睛」。單元測試唔會依賴網絡。

## 本機開啟

用任何靜態伺服器都可以，例如：

```bash
cd hai-gwong
python3 -m http.server 8080
```

然後用手機或電腦瀏覽器打開提示嘅位址。直接用檔案協議打開 `index.html` 通常都可以玩（無需建置步驟）。
