# 今日訓導檢查手機櫃

用電筒照儲物櫃門嘅一條罅隙，記住冇交機嘅格——一隻喺瀏覽器即玩、以手機直立為主嘅校園值日小品。櫃裏面嘅電話打橫擺。題材係觀察同記憶，語氣輕鬆，唔會公開任何同學姓名，亦唔會羞辱學生。

線上試玩：<https://tlc-cmyk.github.io/hai-gwong/>

## 點玩

1. 打開 `index.html`（或上面嘅 GitHub Pages 連結），建議將裝置直立，撳「開始晨檢」。
2. 走廊分成四頁：**中一、中二、中三、中四**，每個年級 160 個儲物櫃，編號由頂上開始（例如中一係 1A01–1A40、1B01–1B40、1C01–1C40、1D01–1D40；中二至中四同樣用 2A01–2D40、3A01–3D40、4A01–4D40）。可用左右滑動、底部年級掣、滾輪或方向鍵換頁。計時係四頁共用，唔會因換頁而重設。
3. **檢查（共 45 秒）**：走廊會變暗。移動手指或滑鼠，控制電筒嘅圓形光圈（光會略為上移，避免手指遮住櫃門）。只有光圈裏面先睇得到櫃門顏色，同埋從櫃門罅隙睇到裏面有冇電話。光圈以外只剩暗暗嘅櫃格輪廓，方便你掃過。已照過嘅格會留下一個淡淡嘅點，但唔會提示裏面有冇電話。檢查途中記得滑去其他年級。
4. 每一局每個年級會隨機抽出 **4** 格冇放電話（違規），四頁合共 **16** 格；其餘都有電話。請記住冇電話嘅年級同櫃號（例如 2B17）。
5. **點選（共 15 秒）**：電筒熄滅，罅隙亦唔再透露內容；櫃門顏色同編號仍然可見。喺呢 15 秒內滑去相應年級，點選你記得冇電話嘅儲物櫃，再撳一次可以取消。時間一到就鎖定選擇。
6. 結果會顯示查中、誤報、漏查、評級，同埋按年級列出櫃號（例如「中二 2B17」），以及存在呢部裝置嘅自我最佳。畫面上亦會標記答對、誤報同漏查嘅櫃號。

標題、遊戲同結果畫面都有「聲音：開／關」。請用手機直立玩；如果裝置打橫，會提示「請將裝置直立」。櫃隙裏見到嘅電話係打橫擺嘅。桌面瀏覽器用滑鼠移動即可照櫃，唔使先撳一下；亦可用底部年級掣或滾輪換頁。

## 操作一覽

| 操作 | 作用 |
| --- | --- |
| 移動滑鼠（檢查階段） | 電筒光圈跟隨，無須點擊即可從罅隙查看 |
| 手指按住並移動（檢查階段） | 手指即電筒；光圈略為上移 |
| 左右滑動／撳年級／滾輪／方向鍵 | 喺中一至中四換頁（檢查同點選階段都得） |
| 點擊／輕觸櫃格（點選階段） | 選取或取消「冇交機」標記 |
| 「聲音：開／關」 | 靜音或開聲 |

檢查階段掃柜時，普通左右移動電筒唔會換頁；快速橫向輕掃、從上下邊緣或兩側開始滑，或者用底部年級掣，先會翻去下一版。

## 評級

分數：每查中一格 +100，每誤報一格 −25，最低 0 分。十六格全中且零誤報為 1600 分。

| 條件 | 評級 |
| --- | --- |
| 16 格全中，零誤報 | 火眼金睛 |
| 至少 12 格查中，誤報不多於 2 | 細心值日 |
| 至少 10 格查中且誤報不多於 4，或至少 8 格查中且誤報不多於 2 | 合格 |
| 至少 6 格查中，誤報不多於 6 | 漏咗幾格 |
| 誤報至少 8 格，而且誤報多過查中 | 亂點 |
| 其餘（包括完全唔點） | 要再練 |

最佳分數存在瀏覽器 localStorage（鍵名 `hai-gwong-best-v3`，同舊版 120 格櫃牆嘅紀錄分開）。

## 技術

- 單資料夾靜態網頁：`index.html`、`style.css`、`engine.js`、`audio.js`、`game.js`，無建置步驟、無外部 CDN。
- 畫面用 Canvas 即場繪製（原創扁平描邊校園風：乳白色走廊、雜色儲物櫃、電筒圓光）。每個年級嘅櫃牆為 10×16＝160 格，配合直立畫面；櫃門寫住 1A01 呢類編號。從櫃隙睇進去，電話係打橫而且較薄嘅機身。
- 聲音用 Web Audio 即時合成（柔和電筒低鳴、照櫃輕響、點選、校鐘、倒數提示、結果短句），唔靠取樣檔。
- 玩法邏輯集中喺 `engine.js`，可以用 Node 做無介面測試：

```bash
node test-engine.mjs
```

測試會檢查：標題「今日訓導檢查手機櫃」、四個年級各 160 格櫃（編號 1A01–4D40）、每頁 4 格空櫃合共 16 格、每頁顏色互異、45 秒檢查後 15 秒點選（換頁唔會重設計時或重抽空櫃）、只有檢查階段而且光圈蓋住當前頁櫃隙先可以看見內容、點選階段不能偷睇、評分同評級，以及「先照晒四頁所有空櫃再準確點選」嘅記憶機械人會得到「火眼金睛」。

## 本機開啟

用任何靜態伺服器都可以，例如：

```bash
cd hai-gwong
python3 -m http.server 8080
```

然後用手機或電腦瀏覽器打開提示嘅位址。直接用檔案協議打開 `index.html` 通常都可以玩（無需建置步驟）。
