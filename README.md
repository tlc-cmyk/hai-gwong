# 隙光晨檢

用電筒照儲物櫃門嘅一條罅隙，記住冇交機嘅格——一隻喺瀏覽器即玩、以手機直立為主嘅校園值日小品。題材係觀察同記憶，語氣輕鬆，唔會公開任何同學姓名，亦唔會羞辱學生。

線上試玩：<https://tlc-cmyk.github.io/hai-gwong/>

## 點玩

1. 打開 `index.html`（或上面嘅 GitHub Pages 連結），撳「開始晨檢」。
2. **檢查（30 秒）**：走廊會變暗。上下移動手指或滑鼠，控制電筒嘅圓形光圈（光會略為上移，避免手指遮住櫃門）。只有光圈裏面先睇得到櫃門顏色，同埋從櫃門罅隙睇到裏面有冇電話。光圈以外只剩暗暗嘅櫃格輪廓，方便你掃過。已照過嘅格會留下一個淡淡嘅點，但唔會提示裏面有冇電話。
3. 每一局會隨機抽出 **8** 格冇放電話（違規），其餘 112 格都有電話。請記住嗰 8 個格號。
4. **點選（10 秒）**：電筒熄滅，罅隙亦唔再透露內容；櫃門顏色同編號仍然可見。喺呢 10 秒內點選你記得冇電話嘅儲物櫃，再撳一次可以取消。時間一到就鎖定選擇。
5. 結果會顯示查中、誤報、漏查、評級，同埋存在呢部裝置嘅自我最佳。畫面上亦會標記答對、誤報同漏查嘅格號。

標題、遊戲同結果畫面都有「聲音：開／關」。建議用手機直立玩；如果裝置打橫，會提示「請將裝置直立」，並盡量將 120 個櫃格排入畫面。桌面瀏覽器用滑鼠移動即可照櫃，唔使先撳一下。

## 操作一覽

| 操作 | 作用 |
| --- | --- |
| 移動滑鼠（檢查階段） | 電筒光圈跟隨，無須點擊即可從罅隙查看 |
| 手指按住並移動（檢查階段） | 手指即電筒；光圈略為上移 |
| 點擊／輕觸櫃格（點選階段） | 選取或取消「冇交機」標記 |
| 「聲音：開／關」 | 靜音或開聲 |

## 評級

分數：每查中一格 +100，每誤報一格 −25，最低 0 分。全中且零誤報為 800 分。

| 條件 | 評級 |
| --- | --- |
| 8 格全中，零誤報 | 火眼金睛 |
| 至少 6 格查中，誤報不多於 1 | 細心值日 |
| 至少 5 格查中且誤報不多於 2，或至少 4 格查中且誤報不多於 1 | 合格 |
| 至少 3 格查中，誤報不多於 3 | 漏咗幾格 |
| 誤報至少 4 格，而且誤報多過查中 | 亂點 |
| 其餘（包括完全唔點） | 要再練 |

最佳分數存在瀏覽器 localStorage。

## 技術

- 單資料夾靜態網頁：`index.html`、`style.css`、`engine.js`、`audio.js`、`game.js`，無建置步驟、無外部 CDN。
- 畫面用 Canvas 即場繪製（原創扁平描邊校園風：乳白色走廊、雜色儲物櫃、電筒圓光）。
- 聲音用 Web Audio 即時合成（柔和電筒低鳴、照櫃輕響、點選、校鐘、倒數提示、結果短句），唔靠取樣檔。
- 玩法邏輯集中喺 `engine.js`，可以用 Node 做無介面測試：

```bash
node test-engine.mjs
```

測試會檢查：120 格櫃、8 格空櫃、顏色互異、30 秒檢查後 10 秒點選、只有檢查階段而且光圈蓋住櫃隙先可以看見內容、點選階段不能偷睇、評分同評級，以及「先照晒所有空櫃再準確點選」嘅記憶機械人會得到「火眼金睛」。

## 本機開啟

用任何靜態伺服器都可以，例如：

```bash
cd hai-gwong
python3 -m http.server 8080
```

然後用手機或電腦瀏覽器打開提示嘅位址。直接用檔案協議打開 `index.html` 通常都可以玩（無需建置步驟）。
